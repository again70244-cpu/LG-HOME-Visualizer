# LG-HOME-Visualizer

LG 家電空間預覽系統 — 把去背的商品圖，以**真實比例**合成進客戶家中的實際照片。

`index.html` 是一個零依賴的單檔網頁工作台，直接用瀏覽器開啟即可使用。
**所有影像處理都在瀏覽器本機完成，照片不會上傳到任何伺服器**（客戶家中照片屬個資）。

## 使用流程

| 階段 | 內容 |
|---|---|
| 1 載入素材 | 上傳客戶空間照片 + 商品去背 PNG |
| 2 真實比例校正 | 設定商品實際高度、拍照時的相機高度、拉出視平線 |
| 3 擺放與透視 | 拖曳定位、尺寸微調、垂直透視、水平鏡射 |
| 4 陰影與接地 | 接觸陰影、投射陰影、地板倒影 |
| 5 影像融合 | 色調匹配、亮度色溫、邊緣修整、雜訊匹配 |
| 6 檢視與輸出 | 光影情境預設、比對原圖、輸出原始解析度合成圖 |

## 比例是怎麼算出來的

採用單視圖測量學（single-view metrology）。對任何站在地面上的物體：

```
畫面高度(px) = (物體底部y − 視平線y) × 實際高度 / 相機高度
```

只要校正好視平線與相機高度，把商品往畫面深處拖曳時尺寸會自動縮小，
比例永遠正確。狀態列會即時顯示推算出的實際尺寸、該位置的比例尺（px/cm），
以及「尺寸微調」偏離真實比例的百分比。

## 擬真度的關鍵

依效果由大到小：

1. **接觸陰影** — 物體與地面接觸處的深色暗影，是判斷「有沒有真的站在那裡」最主要的線索
2. **投射陰影** — 由 alpha 剪影經傾斜＋壓縮變形投影到地面
3. **正確比例與透視** — 見上節
4. **地板倒影** — 亮面地板（磁磚、拋光石英磚）適用
5. **色調匹配** — 取樣商品落點周圍的環境色，調整去背圖的白平衡、黑階與對比
6. **邊緣修整** — alpha 腐蝕，清除去背殘留的白邊
7. **雜訊匹配** — 讓過於乾淨的商品圖貼近照片本身的顆粒

## 限制

**商品的角度不能改變。** 去背圖是 2D 的，四點變形只能修正約 ±10° 的小落差。
要把商品放進不同視角的空間，需要準備對應角度的去背圖
（建議每個商品備妥正面、左前 45°、右前 45° 三張）。

去背圖長邊建議 1500px 以上，否則放大後會糊。

## 後續方向

- 手動遮罩：讓前景物件（沙發、櫃體）擋在商品前面
- 商品資料庫：預存型號、實際尺寸與多角度去背圖
- AI 影像融合（harmonization）：以 3D/2D 合成結果為結構基礎，只調整光線與色調而不改變商品外觀
